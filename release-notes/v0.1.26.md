# v0.1.26 — a captain can switch a live member's model route

Release on npm `latest` at the time of writing; recommended host: Harness `0.2.1-rc.2`.

- New captain tool `agent_teams_set_member_model`: change one member's provider/model/effort without recreating it. A live child keeps its session and history — the next prompt assembly and request use the new route, and the host appends its own `[model changed: …]` notice. A member that is not live has the route persisted for its next activation.
- The activity panel stays consistent: the member route badge and the task model label read the updated snapshot.
- `lib/` build output was regenerated for this release; see [v0.1.25](./v0.1.25.md) for the host-compatibility history.
